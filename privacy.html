プライバシーポリシー

最終更新日:2026年9月2日

投資デビュー診断(以下「本サービス」)は、ご利用いただく方のプライバシーを尊重し、 個人情報の取り扱いについて次のとおり定めます。

1. 診断のために入力していただく情報

入力された金額は、サーバーに送信されません。 すべてお使いの端末のブラウザの中だけで計算・保存されます。

本サービスでは、診断のために収入・支出・住まいの形態・質問への回答を入力していただきます。 これらの情報は、お使いのブラウザの中だけで処理され、当方のサーバーや外部の事業者に 送信されることはありません。 本サービスにはデータを送信するためのプログラムが含まれていないため、 当方がこれらの内容を知ることはできません。

診断の途中でページを閉じても続きから再開できるよう、入力内容は ブラウザの「ローカルストレージ」という保存領域に一時的に保存されます。 保存されるのは次の4つだけです。

  • 診断の途中データ(保存名:toshi-debut-progress)
    住まいの形態・入力した金額・質問への回答。 診断が完了した時点で自動的に削除されます。 再開の確認画面で「いいえ、最初からやり直す」を選んだときも削除されます。
  • やることリストのチェック状態(保存名:toshi-debut-todo)
    有料機能のチェックリストで、どの項目にチェックを付けたかの記録です。
  • お支払い中の一時データ(保存名:toshi-debut-return)
    決済のために外部の決済画面へ移動するあいだ、診断内容を一時的に預かるものです。 お支払いが終わってこのサイトに戻った時点で削除されます。
  • 購入済みかどうかの記録(保存名:toshi-debut-paid)
    有料機能をご利用いただける状態かどうかを示す記録です。 金額やお支払い方法の情報は含みません。

これらはお使いの端末のブラウザ内にのみ保存され、別の端末やブラウザには引き継がれません。 ブラウザの設定から「サイトデータの削除」を行えば、いつでもご自身で消すことができます。

2. 決済に関する情報

有料機能の決済は、決済代行会社である Stripe(ストライプ) が処理します。 お支払い方法として、クレジットカードのほかに PayPay をご利用いただけます。

クレジットカード番号・有効期限・セキュリティコード、および PayPay の アカウント情報は Stripe および PayPay 側に直接送信され、 本サービスがこれらの情報を取得・保持することは一切ありません。 PayPay をお選びになった場合は、決済の手続きのために PayPay のアプリまたは サイトへ移動します。

決済に関する情報の取り扱いについては、Stripe のプライバシーポリシーをご確認ください。
https://stripe.com/jp/privacy

3. アクセスに伴って記録される情報

本サービスは GitHub Pages 上で公開されています。 ページを表示する際、ホスティング事業者である GitHub, Inc. のサーバーに IPアドレスやブラウザの種類などの技術的な情報が記録される場合があります。 これは Web サイトの配信に伴って一般的に生じるもので、当方がこれらの情報を 参照・取得することはありません。

また、グラフの描画に外部の配信サービス(jsDelivr)からプログラム(Chart.js)を 読み込んでいるため、同様の技術的な情報が同社に記録される場合があります。

本サービスでは、アクセス解析ツールや広告配信のためのタグは使用していません。 本サービス独自の Cookie も使用していません。

4. 外部サービスへのリンク

診断結果を共有するためのボタン(LINE・X・Instagram)を設置しています。 これらのボタンを押した場合、共有用の文章と本サービスのURLを含んだ画面が 各サービス上で開きます。入力していただいた金額や診断の回答内容が 共有されることはありません。

リンク先の各サービスにおける情報の取り扱いについては、 それぞれのサービスのプライバシーポリシーをご確認ください。

5. 第三者への提供

当方は、ご利用いただく方の個人情報を第三者に提供・販売することはありません。 ただし、法令に基づく開示請求があった場合など、正当な理由がある場合はこの限りではありません。
