# 投資デビュー診断

大学生向けの「投資デビュー診断」Webアプリ。月収・固定費・その他支出を入力すると、
毎月投資に回せる余裕額を無料で診断する。さらに詳しく知りたい人向けに、
NISA積立シミュレーション(利回り3パターン比較・リスク許容度別の資産配分)を
有料コンテンツ(今回は課金導線のみダミー)として用意している。

## 使い方(起動方法)

このフォルダの `index.html` をダブルクリックしてブラウザで開くだけで動く。
サーバーは不要(データ保存もしていないため)。

友人に見せるときは、この `toshi-debut-shindan` フォルダごと渡すか、
`index.html` ファイルを送れば、ダブルクリックだけで同じように動かせる。

### ローカルサーバーで確認したい場合(任意)

```powershell
cd "toshi-debut-shindan"
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開く。

## 画面構成

1. **診断フォーム** — 月収・固定費・その他支出を入力
2. **診断結果(無料)** — 毎月の投資可能額とコメントを表示 → 「もっと詳しく見る」ボタン
3. **課金導線(ダミー)** — モーダルで「購入する(仮)」ボタン。実際の決済は未実装
4. **NISAシミュレーション(有料想定)** — リスク許容度3択 → おすすめ資産配分、
   利回り3%/5%/7%での10年後・20年後の資産推移グラフ(Chart.js)

## 技術構成

- 単一の `index.html` + `app.js`(ビルド不要、npm不要)
- グラフ描画: [Chart.js](https://www.chartjs.org/)(CDN読み込み)
- データベース・サーバーサイドなし。入力値はブラウザ内(メモリ)にのみ保持され、
  リロードすると消える
