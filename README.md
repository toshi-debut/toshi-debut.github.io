# 投資デビュー診断

大学生向けの「投資デビュー診断」Webアプリ。

**無料は「気づきと診断」、有料(300円買い切り)は「具体的なプラン」**という
はっきりした線引きで作っている。

## 使い方(起動方法)

このフォルダの `index.html` をダブルクリックしてブラウザで開くだけで動く。
サーバーもインストールも不要。

友人に見せるときは、この `toshi-debut-shindan` フォルダごと渡すか、
`index.html` と `app.js` の2ファイルを同じ場所に置いて渡せば同じように動く。

### ローカルサーバーで確認したい場合(任意)

```powershell
cd "toshi-debut-shindan"
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開く。

## 無料 / 有料の線引き

| | 内容 |
|---|---|
| **無料** | ①住まいの選択 → 収支入力 ②投資に回せる余裕額 ③見落としがちな支出・同世代比較 ④リスク許容度診断(3択) ⑤**投資タイプの提示**(安定重視型/バランス型/積極型) |
| **↑ここで一区切り** | 「診断はここまで。続きは有料です」＋ぼかし越しのプレビュー＋**¥300で全部見る**ボタン |
| **有料** | ⑥具体的な投資信託の提案(商品名レベル) ⑦NISA積立シミュレーション ⑧目標からの逆算 ⑨やることリスト ⑩SNSシェア用画像 |

実装する場合は `app.js` の `btn-fake-pay` のイベントを Stripe 等に差し替える。

## 画面構成

### 0. 導入画面(無料)

アプリを開くと最初に出る画面。フォームはまだ出さず、期待感を作ることに専念している。

- キャッチコピー「あなたの投資タイプ、当ててみせます。」
- 「3分でわかる」「家計相談1回分(約5,000円相当)の内容が無料」という価値の提示
- 特徴3点(住まい別/平均比較/タイプ判定)
- **「診断をはじめる」ボタン**を押して初めて入力フォームへ進む
- ビジュアルは上下に浮くアイコンと、外へ広がる波紋のアニメーション

### 1. 入力フォーム(無料)

最初に **「一人暮らし / 実家暮らし」** を選ぶと、その住まいで実際にかかる項目だけが出る。

| | 一人暮らし | 実家暮らし |
|---|---|---|
| 収入 | バイト代 / 仕送り・お小遣い | 同左 |
| 固定費 | 家賃・光熱費・通信費・サブスク | 家に入れているお金・通信費・サブスク |
| 変動費 | 食費・交遊費・カフェ/コンビニ・交通費・日用品雑費・趣味娯楽 | 食費(自分の分のみ)・交遊費・カフェ/コンビニ・交通費・趣味娯楽 |

- 食費と交通費は、比較に使う平均額と注記も住まいごとに切り替わる
- 住まいを切り替えても入力済みの金額は保持される
- 余裕額の計算は「収入 − 表示中の項目の合計」で共通(非表示の項目は 0 扱い)
- 金額欄はすべて **3桁カンマ区切りで表示**(内部では数値のまま保持)
- 入力するそばから各セクションの合計額が更新される

### 2. 診断結果(無料)

- **余裕額はカウントアップ演出**で表示。カードは順に浮き上がって出る
- **見落としがちな支出**(サブスク+カフェ/コンビニ+交遊費)の削減インパクト
- **平均より多く使っている項目トップ2**と年間差額
- **同世代平均との比較バー**(項目ごとに 使いすぎ▲/やや多め●/堅実✓)
- **投資タイプ診断**(3択) → タイプ別に色分けされた結果カード
  （🛡️安定重視型 / ⚖️バランス型 / 🚀積極型。値動きの目安と想定利回りつき）

### 3. 利用者の声(無料・課金の壁の手前)

横スクロールするカード形式でレビューを5件表示する。
内容は `app.js` の **`REVIEWS` 配列**にまとめてあるので、実際の声が集まったら
そこを書き換えるだけで差し替えられる(名前・属性・星の数・コメントの4項目)。

### 4. 課金の壁

有料コンテンツの中身が **ぼかし(blur)越しに透けて見える**。
プレビューは選んだタイプの実データで作られるので、「自分の結果が隠れている」状態になる。
「¥300で全部見る」ボタンは光るアニメーション付き。

### 5. 詳細プラン(有料・タブ切り替え)

スクロールが長くなりすぎないよう、**上部固定のタブ5枚**で切り替える。

| タブ | 内容 |
|---|---|
| 📈 積立試算 | **積み上げ棒グラフ**で5年ごとの資産額を表示(元本と運用益を色分け、ホバー/タップで正確な金額と合計を表示)。金額(0〜10万)・期間(1〜40年)・利回り(3/5/7%)を動かすと即再計算。チェックを入れると3利回りを並べた棒グラフに切り替わる。「あと月+1,000/3,000/5,000円」の差額比較つき |
| 💼 投資プラン | タイプ別のテーマ分散ポートフォリオ。商品名の例つき |
| 🎯 目標逆算 | 目標(留学・車・世界一周・結婚資金・タワマン頭金・早期リタイア・自由入力)から必要な毎月の積立額を逆算。「あと月◯円」「◯年◯ヶ月遅れる」を提示 |
| ✅ やること | 5ステップのチェックリスト。進捗バー・完了バナーつき。状態は localStorage に保存 |
| 📱 シェア | **Instagram ストーリーズ用の 1080×1920 画像**を生成・ダウンロード |

どのタブからでも他のタブへ移動できる。タブバーはスクロールしても上に固定される。

## 計算方法

毎月積み立てた場合の将来価値(月複利の年金終価):

```
FV = 毎月の積立額 × ((1 + r/12)^(年数×12) − 1) / (r/12)
```

例: 月1万円・年5%・20年 → 4,110,337円(元本240万円 / 運用益171万円)

目標からの逆算はこの式を積立額について解いたもの。
**必要額は切り上げ**ている(切り捨てると、その額を積み立てても目標にわずかに届かないため)。

## デザインの方針

- **白ベース固定**。OSのダークモード設定には追従しない
- 配色はネイビー(信頼) × グリーン(成長) × ゴールド(特別感)
- 演出：カウントアップ / カードのフェードイン / 課金ボタンの発光 /
  タイプカードのポップイン。すべて `prefers-reduced-motion` で無効化される
- 用語ツールチップ：NISA・インデックスファンドなど11語を辞書化し、
  文中の該当語を自動でボタン化(`GLOSSARY` と `AUTO_TERMS` に追記すれば増やせる)

## 技術構成

- 単一の `index.html` + `app.js`(ビルド不要、npm不要)
- グラフ描画: [Chart.js](https://www.chartjs.org/)(CDN読み込み)
- シェア画像のPNG生成: Canvas 2D API を直接使用(外部ライブラリなし)
- データベース・サーバーサイドなし。入力値はメモリにのみ保持され、リロードで消える
  (例外：やることリストのチェック状態だけ localStorage に保存)
