# 投資デビュー診断

大学生向けの「投資デビュー診断」Webアプリ。

**無料部分は「気づきを与える入口」、有料部分は「本当に価値のある体験」**として
役割をはっきり分けている。

- **無料**: 支出を10項目に分けて入力 → 毎月の余裕額 + 同世代平均との比較 +
  「見落としがちな支出」の削減インパクト
- **有料(課金導線は現在ダミー)**: 積立額・期間・利回りを動かせるNISAシミュレーション、
  「あと月1,000円」の比較、リスク許容度別のポートフォリオ提案、結果カードの画像保存

## 使い方(起動方法)

このフォルダの `index.html` をダブルクリックしてブラウザで開くだけで動く。
サーバーもインストールも不要。

友人に見せるときは、この `toshi-debut-shindan` フォルダごと渡すか、
`index.html` と `app.js` の2ファイルを同じ場所に置いて渡せば同じように動く。

### ローカルサーバーで確認したい場合(任意)

```powershell
cd "toshi-debut-shindan"
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開く。

## 画面構成

### 1. 入力フォーム(無料)

**最初に「一人暮らし / 実家暮らし」を選ぶ**と、その住まいで実際にかかる項目だけが表示される。

| | 一人暮らし | 実家暮らし |
|---|---|---|
| 収入 | バイト代 / 仕送り・お小遣い | 同左 |
| 固定費 | 家賃・光熱費・通信費・サブスク | 家に入れているお金・通信費・サブスク |
| 変動費 | 食費・交遊費・カフェ/コンビニ・交通費・日用品雑費・趣味娯楽 | 食費(自分の分のみ)・交遊費・カフェ/コンビニ・交通費・趣味娯楽 |

- 食費と交通費は、比較に使う平均額と注記も住まいごとに切り替わる
- 住まいを切り替えても、入力済みの金額は保持される
- 余裕額の計算は「収入 − 表示中の項目の合計」で共通（非表示の項目は 0 として扱う）
- 入力するそばから各セクションの合計額が更新される（「入れながら気づく」ための仕掛け）
- 金額欄はすべて **3桁カンマ区切りで表示**される（内部では数値のまま保持）

### 2. 診断結果(無料)

- 毎月投資に回せる目安額と、収入に対する割合
- **見落としがちな支出**: サブスク + カフェ/コンビニ + 交遊費 の合計。
  「半分に減らすと年◯円 → 20年運用で◯円」まで出す
- **平均より多く使っている項目トップ2** と、その年間差額
- **同世代平均との比較バー**: 項目ごとに「使いすぎ / やや多め / 堅実」を判定
  （平均額はサンプル用の参考値。`app.js` の `EXPENSE_ITEMS` の `avg` で調整できる）
- 「無料でわかったこと / 有料でわかること」を並べた課金導線

### 3. 課金導線(ダミー)

モーダルで「購入する(仮)」ボタン。実際の決済処理は未実装。

### 4. 詳細シミュレーション(有料想定)

- **積立額(0〜10万円)・期間(1〜40年)・基準利回り(3/5/7%)** をスライダーとタブで変更でき、
  グラフがその場で再計算される
- グラフは既定で**選択中の利回り1本だけ**を表示する。
  「3%・5%・7%を並べて比較する」にチェックを入れたときだけ3本を重ねて表示する
  （凡例・表も同じ切り替えに追従する）
- **「あと月+1,000 / +3,000 / +5,000円」** で期間終了時にいくら変わるかの比較
- **リスク許容度3択 → 株式のみのテーマ分散ポートフォリオ**
  （全世界株式・S&P500・米国ハイテク・高配当・生活必需品・新興国株を、
  リスク度に応じて配分。具体的なファンド名の例つき）
- **結果カードの画像保存**: 1080×1440 のPNGを生成してダウンロードできる。
  SNSにそのまま貼れる見た目にしてある

## 計算方法

毎月積み立てた場合の将来価値（月複利の年金終価）:

```
FV = 毎月の積立額 × ((1 + r/12)^(年数×12) − 1) / (r/12)
```

例: 月1万円・年5%・20年 → 4,110,337円（元本240万円 / 運用益171万円）

## 技術構成

- 単一の `index.html` + `app.js`（ビルド不要、npm不要）
- グラフ描画: [Chart.js](https://www.chartjs.org/)（CDN読み込み）
- 結果カードのPNG生成: Canvas 2D API を直接使用（外部ライブラリなし）
- データベース・サーバーサイドなし。入力値はブラウザ内（メモリ）にのみ保持され、
  リロードすると消える
- ダークモード対応（OSの設定に追従）
